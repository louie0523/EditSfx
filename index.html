      ℹEditSfx 소개 _□×

      EditSfx는 게임 효과음을 비롯한 모든 짧은 사운드를 손쉽게 다듬기 위한 무료 웹 편집기입니다. 인터넷에서 받은 효과음에 불필요한 앞뒤 공백이 있거나, 원하는 한 부분만 잘라 쓰고 싶을 때, 또는 여러 소리를 이어 붙이거나 겹쳐 새로운 효과음을 만들고 싶을 때 사용합니다.

      별도의 프로그램 설치나 회원가입이 필요 없습니다. 브라우저에서 파일을 올리면 자르기 · 이어붙이기 · 합성은 물론 속도·피치·음량·페이드 같은 세부 편집까지 마친 뒤 MP3 또는 WAV 파일로 바로 내려받을 수 있습니다.

      무엇보다 올린 파일은 어떤 서버에도 전송되지 않습니다. 모든 처리는 여러분의 기기(브라우저) 안에서만 이루어지므로 비공개 음원도 안심하고 다룰 수 있습니다. 게임 개발뿐 아니라 영상 편집, 방송, 알림음 제작 등 다양한 곳에 활용해 보세요.

      ★기능 소개 _□×

      1. 개별 파일 편집 — 자르기와 세부 효과

      파일을 올리면 파형이 표시됩니다. 파형 위를 드래그해 원하는 구간을 선택하고 선택 구간으로 자르기를 누르면 그 부분만 남습니다. 효과음의 앞뒤 공백 제거에 가장 자주 쓰이는 기능입니다. 품질 보호를 위해 최소 길이는 0.026초(약 26ms)로 제한됩니다.

      • 속도 — 음정은 유지한 채 빠르기만 0.5×~2× 범위로 조절합니다.
      • 피치 — 길이는 그대로 두고 음정을 반음 단위(-12~+12)로 올리거나 내립니다.
      • 음량 — 0×~3× 배율로 키우거나 줄입니다. dB 값도 함께 표시됩니다.
      • 페이드인 / 페이드아웃 — 시작·끝을 부드럽게 처리해 ‘툭’ 끊기는 소리를 없앱니다.
      • 역재생 — 사운드를 거꾸로 뒤집어 색다른 효과를 만듭니다.

      자른 부분 미리듣기를 누르면 선택한 구간에 위 효과까지 모두 입힌 소리를 잘라내기 전에 바로 들어볼 수 있습니다. 또한 노멀라이즈(가장 큰 소리가 최대치에 닿도록 음량을 자동으로 키움)와 양끝 무음 제거(앞뒤의 거의 들리지 않는 부분을 자동으로 잘라냄) 버튼으로 한 번에 다듬을 수 있습니다. 효과는 미리듣기와 내보내기에 실시간 반영되며, 효과 파형에 적용으로 결과를 확정해 편집을 이어갈 수 있습니다.

      2. 이어붙이기 — 순서·간격·크로스페이드

      여러 사운드를 차례로 재생되도록 합칩니다. 각 사운드 뒤 간격(초)을 정하면 그만큼 무음이 들어갑니다. 예를 들어 ‘띵’ 소리 뒤 간격을 0.2초로 두고 ‘유리 깨짐’ 소리를 추가하면, 0.2초 후 유리 소리가 이어지는 하나의 파일이 됩니다.

      • 크로스페이드(초) — 간격 대신 다음 소리와 겹쳐 부드럽게 섞이도록 만듭니다. 음악·앰비언스 연결에 좋습니다.
      • 트랙별 효과 — 이어붙이는 각 사운드마다 피치·속도·음량·페이드·역재생을 따로 줄 수 있습니다.
      • 순서 변경 — 항목을 드래그해 순서를 바꿉니다.

      3. 합성 / 믹스 — 겹쳐 쌓기

      여러 사운드를 같은 시간축 위에 겹쳐 하나로 만듭니다. 각 사운드의 시작 시점과 음량을 지정해 배경음 위에 효과음을 얹는 식의 합성을 할 수 있습니다.

      • 좌우 팬(L/R) — 각 소리를 왼쪽·가운데·오른쪽 어디에서 들리게 할지 배치해 입체감을 줍니다(이어붙이기와의 차별 기능).
      • 트랙별 효과 — 겹치는 각 사운드에도 피치·속도·음량 등 효과를 따로 적용합니다.
      • 자동 음량 정규화 — 겹쳐서 소리가 커질 때 깨지지 않도록 전체 음량을 자동으로 맞춥니다(끄면 기존처럼 클리핑만 방지).

      4. 결과 파형 미리보기 · 편집기로 보내기

      이어붙이기와 합성 모두 결과 파형 보기로 합쳐진 소리의 형태를 눈으로 확인할 수 있고, 각 사운드의 작은 파형 썸네일도 함께 표시됩니다. 편집기로 보내기를 누르면 합쳐진 결과가 ‘개별 파일 편집’으로 넘어가 추가로 자르거나 효과를 더할 수 있습니다.

      5. 내보내기와 개인정보

      결과물은 MP3(192kbps) 또는 무손실 WAV로 저장합니다. 서로 다른 샘플레이트·채널의 파일도 자동으로 맞춰 처리합니다. 업로드·로그인·서버 저장이 전혀 없어 작업 내용은 외부로 나가지 않습니다.

      ▤간단 사용법 _□×

      효과음 공백 잘라내기

      1. ‘개별 파일 편집’ 탭에서 파일을 올립니다.
      2. 파형에서 남길 구간을 드래그로 선택합니다.
      3. 선택 구간으로 자르기 → 필요하면 페이드인/아웃을 살짝 적용합니다.
      4. 형식(MP3/WAV)을 고르고 다운로드를 누릅니다.

      두 소리를 0.2초 간격으로 이어붙이기

      1. ‘이어붙이기’ 탭에서 A, B 두 파일을 추가합니다.
      2. A의 뒤 간격을 0.2로 설정합니다(부드럽게 섞으려면 크로스페이드에 값을 넣으세요).
      3. 필요하면 각 트랙의 효과를 펼쳐 피치·음량 등을 조절합니다.
      4. 결과 파형 보기로 형태를 확인한 뒤 합쳐서 다운로드를 누릅니다.

      배경음 위에 효과음을 오른쪽에서 얹기(합성)

      1. ‘합성 / 믹스’ 탭에서 배경음과 효과음을 추가합니다.
      2. 효과음의 시작(초)을 원하는 지점으로, 팬을 오른쪽으로 옮깁니다.
      3. 소리가 깨지면 자동 음량 정규화를 켭니다.
      4. 편집기로 보내기로 결과를 더 다듬거나 바로 합성해서 다운로드합니다.
      ?자주 묻는 질문 _□×
      내 사운드 파일이 서버로 올라가나요?
      아니요. EditSfx의 모든 처리는 여러분의 브라우저 안에서만 이루어집니다. 파일은 어떤 서버로도 전송·저장되지 않습니다.
      어떤 파일 형식을 지원하나요?
      불러오기는 브라우저가 디코딩할 수 있는 mp3, wav, ogg, m4a 등을 지원합니다(브라우저별로 다소 차이가 있습니다). 내보내기는 MP3와 WAV를 지원합니다.
      왜 0.026초보다 짧게 자를 수 없나요?
      지나치게 짧은 구간은 ‘툭’ 하는 잡음(클릭)만 남거나 들리지 않는 경우가 많아, 품질을 위해 최소 길이를 0.026초로 제한했습니다.
      MP3로 저장이 안 되고 WAV로 받아져요.
      MP3 인코더(외부 스크립트)가 네트워크 문제로 로드되지 않은 경우입니다. 이때는 자동으로 WAV로 저장됩니다. 새로고침 후 다시 시도해 보세요.
      상업적으로 사용해도 되나요?
      EditSfx라는 도구 자체는 자유롭게 사용할 수 있습니다. 다만 편집하는 음원의 저작권·라이선스는 사용자 본인이 확인하고 책임져야 합니다.
      모바일에서도 되나요?
      네. 최신 모바일 브라우저에서 동작합니다. 다만 매우 긴 파일은 기기 성능에 따라 처리에 시간이 걸릴 수 있습니다.
